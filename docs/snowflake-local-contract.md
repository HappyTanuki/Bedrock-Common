# Snowflake local state contract

Snowflake reads configuration once per linked library instance, on that instance's first `Snowflake::Generate()` call; a process that links Common once reads it once, and independently linked copies each read it on their own first call. `BEDROCK_COMMON_STATE_DIR` selects the state directory; otherwise the platform default applies. `BEDROCK_SNOWFLAKE_MACHINE_ID`, when present, takes priority over the directory's `machine-id` file. The configured machine ID is a single ASCII digit `0` through `7`, with surrounding ASCII whitespace permitted. Invalid values fail generation rather than being coerced. The cached result, whether a configuration or a failure, is immutable for the lifetime of the library instance, including after environment or file changes. Every instance in a process and every process on a server must observe the same state directory and machine ID.

The registry is a fixed 192-byte version-1 record. Its magic, version, layout, epoch, slot and machine metadata are validated before slots are acquired. Corrupt/incompatible records are rejected and must not be repaired or modified by a failed read. Lock failures on the registration gate or on a slot that is not merely busy map to `kLockFailed` (-10), or to `kUnsupportedPlatform` (-16) when locking is unsupported; busy slots are skipped, and `kSlotsExhausted` (-11) is returned only when every slot is held. Archive YAML identity errors are mapped through `SnowflakeIdentityError` to the matching internal `TranscriberError::kSnowflake*` value and public `ErrorCode` in the `0x101`–`0x110` range; a negative identity is never cast directly to `TranscriberError`.
